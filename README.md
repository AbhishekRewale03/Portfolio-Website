# Portfolio Website

A modern and responsive personal portfolio website built with **React.js** and **Tailwind CSS** to showcase projects, skills, and contact information.

## 🔗 Live Demo - https://portfolio-website-ih3n7a9fi-abhishekrewale03s-projects.vercel.app/
<br/>

## 💻 Features
- Responsive design for mobile, tablet, and desktop screens
- Showcases projects with descriptions and images
- Interactive UI/UX with hover effects and animations
- Contact section with links to email, LinkedIn, and GitHub
- Dark mode support
- <br/>

## 🛠 Tech Stack
- **Frontend:** React.js, Tailwind CSS
- **Animations & Effects:** Framer Motion
- **Deployment:** Vercel
<br/>




## 🚀 Getting Started

1. Clone the repository

- git clone https://github.com/YourUsername/portfolio-website.git
 <br/>

2. Navigate to the project folder

- cd portfolio-website
<br/>

3. Install dependencies


- npm install
<br/>

4. Start the development server


- npm start

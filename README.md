# Abhishek Rewale — Portfolio

A cinematic, responsive portfolio for full-stack software engineer Abhishek Rewale. Built with React, TypeScript, Vite, Tailwind CSS v4, Motion, Lucide, and custom SVG/CSS visual systems.

## Local development

Requirements: Node.js 20.19+ or 22.12+.

```bash
npm install
npm run optimize:assets
npm run dev
```

Open the local URL printed by Vite.

## Quality checks

```bash
npm run lint
npm run typecheck
npm run build
```

The production build is written to `dist/`.

## Deployment

The existing Vercel project deploys the `main` branch with:

- Framework preset: Vite
- Install command: `npm install`
- Build command: `npm run build`
- Output directory: `dist`

## Content notes

- The project visuals are intentionally illustrative UI compositions and do not claim to be production screenshots or real analytics data.
- LinkedIn, GitHub, live project links, and the downloadable resume are wired to Abhishek's supplied destinations.

## Asset credits

The hero and about illustrations were created specifically for this portfolio using OpenAI ImageGen. High-resolution sources live in `assets-src/`; optimized WebP/JPEG delivery assets are generated by `npm run optimize:assets`. All remaining visual elements are custom React, CSS, or SVG compositions.
